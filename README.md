# Task Management Web App

A responsive task management web application built using HTML, CSS, JavaScript, Python Flask, and SQLite.

## Features

- User Registration and Login
- Secure Password Hashing
- Add New Tasks
- Edit Tasks
- Delete Tasks
- Mark Tasks as Pending or Completed
- SQLite Database Integration
- User-specific Task Management
- Responsive Design
- Simple and User-friendly Interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Python
- Flask
- SQLite
- Werkzeug
